## 🔧 Core Utility: DirectoryScanner

A clean, native Python utility class designed for background directory monitoring, recursive subfolder traversal, and automated file-purging tasks. It keeps storage pipelines clear of 0-byte clutter generated by legacy processes or partial uploads.

### 🚀 Key Features
*   **Recursive Traversal:** Seamlessly sweeps target root folders and all nested subdirectories via `os.walk`.
*   **Periodic Automation:** Runs continuously in a low-overhead background loop on a customizable polling interval.
*   **Fail-Safe Resilience:** Handles locked system files, permission restrictions, or files deleted mid-scan without crashing the pipeline.
*   **Zero Dependencies:** Built entirely using native Python standard library modules (`os`, `time`, `sys`).
